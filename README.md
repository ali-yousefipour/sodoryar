# صدوریار — سامانه چندشرکتی خدمات تاکسیرانی

نسخه اولیه وب مبتنی بر **PHP 8.2+ / MySQL 8 یا MariaDB 10.6+**، سازگار با هاست اشتراکی لینوکس و بدون Node یا سرویس دائمی. این پروژه با تحلیل فایل‌های قابل‌خواندن بسته اجرایی `TaxiServiceManager.exe` طراحی شده است؛ به معنای انتقال کامل سورس پایتون یا بازتولید همه رفتارهای ناشناخته EXE نیست.

## امکانات پیاده‌شده

- شرکت‌های متعدد، ورود به پنل مجزای منطقی هر شرکت و نقش‌های `superadmin`، `company_admin` و `operator`.
- تفکیک داده‌های مشتری، خدمات، فاکتور، اقلام، گزارش و کاربران بر اساس `company_id` در سمت سرور.
- صدور فاکتور چندخدمتی با ثبت snapshot مبالغ و عنوان، تراکنش DB، شماره یکتا و صفحه چاپ.
- مدیریت مشتریان و تعرفه‌ها، کاربران شرکت، گزارش مجموع نقد/کارتخوان، شمارنده‌های داشبورد و ثبت لاگ عملیات.
- فرم‌های راست‌به‌چپ، واکنش‌گرا، CSRF، نشست HttpOnly، هش رمز، prepared statements و کنترل نقش.

## نصب روی هاست اشتراکی

1. در cPanel یک دیتابیس MySQL با کاربر اختصاصی ایجاد کنید.
2. فایل `database/schema.sql` را با phpMyAdmin وارد کنید.
3. `.env.example` را به `.env` کپی و مشخصات دیتابیس و نشانی سایت را تنظیم کنید. فایل `.env` را **خارج از Document Root** نگه دارید.
4. Document Root دامنه یا زیردامنه را به پوشه `public/` همین پروژه اشاره دهید. `src/`، `scripts/` و `database/` نباید از وب قابل دریافت باشند.
5. در محیط دارای PHP CLI، یک بار `php scripts/create-admin.php admin "مدیر سامانه"` را اجرا کنید و رمز قوی را از stdin وارد کنید. اگر هاست CLI ندارد، از پشتیبانی هاست برای اجرای همین دستور امن استفاده کنید؛ اسکریپت نصب عمومی از طریق وب عمداً وجود ندارد.
6. با HTTPS وارد سایت شوید، شرکت بسازید و مدیر و اپراتور برای هر شرکت تعریف کنید.

## استقرار خودکار GitHub Actions

Workflow `deploy-shared-host.yml` پس از **هر Push به شاخه `main` بدون فیلتر مسیر فایل‌ها** یا اجرای دستی فعال می‌شود. آدرس FTP برابر `2870352177.cloudylink.com:21` و Secretهای گیت‌هاب `ftp` (نام کاربری) و `pass` (رمز) هستند. نام `svg` فعلاً به‌عنوان مسیر نسبی مقصد FTP در نظر گرفته شده است.

- فایل‌های `public/` و `src/` به ترتیب در `svg/public/` و `svg/src/` بارگذاری می‌شوند.
- مسیر Document Root روی هاست باید **`svg/public`** باشد؛ در غیر این صورت آدرس سایت کار نخواهد کرد.
- دیتابیس، `.env`، اسکریپت ایجاد مدیر، تست‌ها و فایل‌های Git به FTP ارسال نمی‌شوند.
- اتصال با **FTPS صریح (TLS روی پورت ۲۱)** برقرار می‌شود؛ هاست باید از TLS پشتیبانی کند. انتقال ناامن FTP مجاز نشده است.
- فایل‌های قدیمی هاست حذف نمی‌شوند. موفق شدن FTP به معنای تأیید عملکرد سایت یا اعمال دیتابیس نیست.

**نکته:** اگر PHP روی مسیر فعلی هاست/وب‌سرور نصب است اما امکان تعیین Document Root وجود ندارد، باید پوشه `public` را به صورت ریشه وب منتشر کنید و باقی فایل‌های برنامه را بیرون از `public_html` قرار دهید؛ از انتقال کورکورانه کل پروژه به `public_html` خودداری کنید.

## مواردی که هنوز در این نسخه وجود ندارند

- درگاه و پروتکل ارتباط واقعی کارتخوان PAX (DLL ویندوزی مستقیماً روی هاست لینوکسی اجرا نمی‌شود). برای این بخش یک عامل واسط امن روی رایانه ویندوزی یا API رسمی پرداخت لازم است.
- چاپ دقیق حرارتی ۸۰ میلی‌متری/A5، تنظیم قالب‌های چاپ، ثبت و استعلام قبض، محاسبه پورسانت و خروجی اکسل.
- ویرایش/حذف رکوردها، فیلتر/صفحه‌بندی پیشرفته، بازیابی رمز، محدودسازی تلاش ورود، جابه‌جایی مالکیت و غیرفعال‌سازی شرکت/کاربر، کنترل صحت الگوریتم کد ملی.
- تست با دیتابیس واقعی، تست مرورگر و بررسی همه رفتارهای نسخه پایتون (سورس آن ارائه نشده است).

## نکات امنیتی و عملیاتی

- این پروژه یک MVP است و پیش از داده‌برداری واقعی/پرداخت باید تست نفوذ، پشتیبان‌گیری، محدودسازی ورود، لاگ‌گیری خطا و چرخه بازیابی دسترسی تکمیل شود.
- `company_id` کلید جداسازی داده‌هاست؛ داده‌ها از لحاظ فیزیکی در یک دیتابیس مشترک قرار دارند.
- `pos_ref` در این نسخه توسط اپراتور وارد می‌شود و **تأیید بانکی تراکنش نیست**.
- برای کارکرد چندشرکتی، اپراتور شرکت نباید بتواند شرکت جاری را با پارامتر درخواست تغییر دهد؛ شناسه از نشست معتبر خوانده می‌شود.
